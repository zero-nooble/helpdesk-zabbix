# Zabbix Dependencies

## Project Overview
Python project for working with Zabbix dependencies.

## Key Files
- `kilo.json` - Kilo configuration
- `AGENTS.md` - This file, contains project instructions

## Models

### NetworkService
Содержит следующую информацию:
- **наименование** (name) - название сервиса
- **Location** - связь с Location (локация)
- **Object** - связь с Object (объект)
- **Service** - связь с Service (тип сервиса)
- **Network Node** - связь с NetworkNode (узел сети)
